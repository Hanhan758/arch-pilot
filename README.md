# ArchPilot —— AI 时代零基础架构思维与工程总控开源指南

> **让不懂代码的人，也能看懂 AI 交上来的架构方案、抓出工程暗坑、稳稳当好自己的技术总控。**

在 AI 编程时代，零基础用户最容易遇到的痛点，往往不是“不会写 `for` 循环”，而是：
- 刚让 AI 做出原型很快，加了几个功能就开始“改一处崩三处”；
- AI 给你讲了一堆“聚合根、端口、乐观锁、WAL、TDD”，听得云里雾里不敢拍板；
- 只能靠 AI 口头保证“全改好了”，不知道怎么防越权写入、防隐私泄露、防删库跑路。

**ArchPilot** 将这些真实痛点拆成一套 **6 周可落地的结构化开源知识库 + 3 合 1 AI 陪学与审校套件**，并用完全脱敏的 **`TALOS-Lite`**（智能体控制底座公开教学模型）贯穿全书，教你用生活常识掌握软件架构的底层逻辑。

---

## 核心内容亮点

1. **6 周零基础总控路线（每周 3–5 小时）**：不教编程语言语法，专注数据边界、版本隔离、单向分层、并发账本、自动验收与平台打包。
2. **`TALOS-Lite` 脱敏标杆模型**：拒绝“猫狗继承动物”玩具示例，以真实运转的 6 大控制底座积木（状态账本、待审提议箱、工作区边界、不可变资产盒、执行安检门、能力身份证）为活教材。
3. **常备工具箱**：收录全量 **大白话术语翻译表** 与 **总控审校 AI 10 条反问清单**（支持网页交互式勾选进度）。
4. **3 合 1 AI 陪学套件**（均提供通用 Prompt 一键复制 + 标准 `SKILL.md` 安装包）：
   - **苏格拉底零基础导师（`arch-tutor`）**：用生活类比与极简图解逐层带学，每次只问 1 题确认真懂；
   - **“老板验货”模拟考官（`arch-examiner`）**：故意提交藏有工程暗坑的方案，让你练就总控挑刺与拍板肌肉记忆；
   - **真实项目体检助手（`arch-auditor`）**：严格只读诊断你自己的 AI 编程项目，输出零基础能看懂的红/黄/绿灯体检单。

## 本地预览与门禁校验

前置依赖：Node.js 20+、Python 3.10+。

```bash
# 1. 安装文档站依赖
npm install

# 2. 启动本地实时预览（内置中文搜索与 Mermaid 图表）
npm run docs:dev

# 3. 运行全套自动化门禁（脱敏检查 + 套件一致性 + 单元测试 + 静态构建）
npm run check:all
```
