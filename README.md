# ArchPilot —— AI 时代零基础架构思维与工程总控开源指南（v1.0）

> **让不懂代码的人，也能看懂 AI 交上来的架构方案、抓出工程暗坑、稳稳当好自己的技术总控。**

在 AI 编程时代，零基础用户最容易遇到的痛点，往往不是“不会写 `for` 循环”，而是：
- 刚让 AI 做出原型很快，加了几个功能就开始“改一处崩三处”；
- AI 给你讲了一堆“聚合根、端口、乐观锁、WAL、TDD”，听得云里雾里不敢拍板；
- 只能靠 AI 口头保证“全改好了”，不知道怎么防越权写入、防隐私泄露、防删库跑路。

**ArchPilot v1.0** 将这些真实痛点拆成了一套 **完整的 6 周零基础架构学习路径 + `TALOS-Lite` 脱敏教学模型 + 3 合 1 AI 陪学与审校套件**，教你用生活常识掌握软件架构的底层逻辑。

---

## 核心内容亮点

1. **完整 6 周零基础总控路线（每周 3–5 小时）**：涵盖数据与规则、Git 分支与真假账本、OOP 聚合与单向分层、并发锁与人机权限隔离、TDD 与绞杀者无损重构、纯内核与不可打包层边界，配套 **高频 12 问 FAQ**。
2. **`TALOS-Lite` 脱敏标杆模型**：以真实运转的多智能体控制底座为原型，提炼为 **6 大架构积木 + 9 份 ≤60 行教学样板 +《双向耦合无损重构实战复盘》**。
3. **常备工具箱**：收录 **17 条大白话术语翻译表** 与 **总控审校 AI 10 条反问清单**（支持浏览器本地持久化交互勾选）。
4. **3 合 1 AI 陪学套件 v1.0.0**（均提供通用 Prompt 一键复制 + 标准 `SKILL.md` 安装包 + 离线 6 关题库）：
   - **苏格拉底零基础导师（`arch-tutor`）**：先打比喻、再画简图与样板映射、一句话总控收口、每次只问 1 题确认真懂；
   - **“老板验货”模拟考官（`arch-examiner`）**：每周 2 套轮换暗坑蓝图 + 综合大考，100 分制四维量化打分复盘；
   - **真实项目体检助手（`arch-auditor`）**：严格只读、隐私脱敏输出《大白话架构体检报告》与最小步修复指令。

## 本地预览与 5 道质量门禁校验

前置依赖：Node.js 20+、Python 3.10+。

```bash
# 1. 安装文档站依赖
npm install

# 2. 启动本地实时预览（内置中文全文检索与 Mermaid 图表）
npm run docs:dev

# 3. 一键运行全部 5 道自动化门禁与构建（GATE-01 ~ GATE-05 + 单元测试 + 静态构建）
npm run check:all
```
