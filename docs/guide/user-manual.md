### 1.2 站内 3 个必用实用功能

1. **全站中文秒搜（右上角「搜索概念或清单」或按快捷键 `⌘K` / `Ctrl+K`）**
   - 场景：编程 AI 突然丢给你一个词（比如 `乐观锁`、`聚合根`、`WAL`、`Fail-Closed`、`棘轮`）。
   - 操作：打开搜索框直接打中文关键词，立刻定位到术语表里的“一句话生活类比”以及对应周次的实战图解。
2. **可交互勾选的《10 条反问清单》（进入 [总控审校 AI 10 条反问清单](/toolkit/review-checklist)）**
   - **进度实时统计**：每勾选一条，顶部进度条自动更新 `当前已核验 X / 10 项（XX%）`，且状态自动保存在当前浏览器的本地存储中，**刷新或明天再打开都不会丢**。
   - **一键发给 AI 对质**：
     - 点 **「复制未核验条目发给 AI」**：系统会自动把你还没打勾的问题整理成带编号的审校追问话术复制到剪贴板，直接粘贴给正在干活的 AI 即可；
     - 点 **「复制全部 10 条」**：适合重要里程碑验收时做全套盘问；
     - 点 **「重置勾选」**：开启下一个新需求评审前一键清零重新核验。
3. **提示词一键复制卡片（在 [AI 陪学套件](/ai-kit/) 各子页面中）**
   - 点 **「展开查看」** 可阅读完整提示词全文，再点 **「收起正文」** 折叠；
   - 点 **「一键复制提示词」**，按钮会变为 **「已复制提示词」**（卡片会自动剥离给程序看的头部元信息，你复制到的就是干净直接能粘贴给 AI 的正文）。

## 二、3 合 1 AI 陪学套件保姆级实操教程

这套套件的核心思路是：**学（导师）→ 练（考官）→ 用（体检助手）**，并且全部提供“网页一键复制版”与“本地 Agent Skill 安装版”。

### 2.1 苏格拉底零基础导师（`arch-tutor`）怎么用？
- **适用时机**：看教程某一段没完全理解、想确认自己是不是真懂、或想把别的 AI 写的复杂技术方案翻成人话。
- **使用步骤**：
  1. 打开站内 [1. 苏格拉底零基础导师](/ai-kit/tutor)，点击 **「一键复制提示词」**；
  2. 打开任意常用 AI 新建空白对话，直接粘贴发送；
  3. 用下面任意一句开场提问（效果最好）：
     - *跟学用*：“我刚看完 ArchPilot 第 2 周，还是分不清‘权威账本’和‘SQLite 索引库’的区别，请用生活例子考考我。”
     - *翻黑话用*：“下面这段话是编程 AI 给我的方案，但我看不懂，请按你的规则用大白话逐段翻译，并告诉我作为老板该盯哪一条底线：[粘贴 AI 回复]。”
- **正常体验长什么样**：导师绝对不会长篇大论甩术语，而是严格走 **生活类比 → 极简关系图 → 一句话总控收口 → 只问你 1 个小问题**。只有等你回答确认懂了，它才会讲下一个知识点。

### 2.2 “老板验货”模拟考官（`arch-examiner`）怎么用？
- **适用时机**：每周学完 1 章后花 5–10 分钟实战练手，训练“一眼识破 AI 偷懒暗坑”的直觉。
- **标准演练 4 步**：
  1. 打开 [2. “老板验货”模拟考官](/ai-kit/examiner)，复制提示词并新建对话发给 AI；
  2. 发送关卡通关口令：
     - 分周练习：**“请开启 Week 1 关卡”**（支持 `Week 1` 至 `Week 6`，每周有 2 套轮换暗坑题）；
     - 毕业实战：**“请开启综合大考”**（跨周随机融合 3 个隐蔽暗坑）；
  3. **接招挑刺**：AI 会装成很客气、但偷偷图省事的研发 AI 交一份 200–350 字方案。别急着说“好”，对照 [10 条反问清单](/toolkit/review-checklist) 追问它 2–3 轮（例如：“你改这个有没有走 Schema 校验？”“如果两人同时改会不会覆盖？”“老测试你跑了吗？”）；
  4. **揭晓评分**：你觉得查差不多了，回复 **“我查完了，揭晓答案吧”**。它会立刻切回考官模式，按 100 分制 4 维打分（防越权与隐私 30 分 / 数据一致性与并发 25 分 / 模块分层与解耦 25 分 / 测试验证与稳健演进 20 分），并告诉你漏了哪个暗坑以及下次发给真实编程 AI 的一句话纠偏指令。
- **离线备选**：没开 AI 时，可以直接去 [经典 6 关题库自测（离线版）](/ai-kit/exam-bank) 点开折叠答案刷 6 道标准案例题。

### 2.3 真实项目体检助手（`arch-auditor`）怎么用？
- **适用时机**：你自己用 AI 写了一个小工具/网站/自动化脚本，开始出现“改这里坏那里”、不确定有没有隐私泄露风险、或者想做小步整理时。
- **方式 A：网页版对话体检（零安装）**
  1. 打开 [3. 真实项目体检助手](/ai-kit/auditor)，复制提示词发给 AI；
  2. 把你项目的两样信息发给它（不需要发完整敏感代码）：
     - 根目录文件结构树（Mac/Linux 终端在项目文件夹里运行 `find . -maxdepth 3 -not -path '*/node_modules*' -not -path '*/.git*'` 即可得到）；
     - 用 3 句话说明：“这个项目现在干什么用、最近改功能最怕哪里崩、打算往哪演化”。
  3. 你会收到固定 5 板块的《大白话架构体检报告》：只读脱敏自证声明 + 4 维红/黄/绿灯评级 + 前 3 大隐患生活类比 + 不推倒重写的 3 步微调路线 + 可直接发给编程 AI 的修复指令。
- **方式 B：本地编程 Agent 自动只读体检（推荐）**
  - 按 [主流 AI 平台安装与接入指南](/ai-kit/install-guides) 装好 `skills/arch-auditor/SKILL.md` 后，在你的项目窗口里直接说：“启用 `arch-auditor` 对当前项目做一次大白话只读架构体检。”
  - **安全底线**：如果客户端弹窗询问是否授予文件写入或删除权限，**一律点拒绝**——体检全程只需要只读权限。

### 2.4 各主流 AI 平台接入速查

| 平台 | 接入方法 |
| :--- | :--- |
| **ChatGPT / Claude 网页版** | 临时用直接粘贴 Prompt 为首条消息；长期用推荐放进 **Projects → Instructions** 中持久生效 |
| **DeepSeek / Kimi / 豆包** | 新建空白对话，把 Prompt 作为首条消息发送即可（不同助手建议分开对话窗口） |
| **Antigravity / Claude Code / Codex** | 将仓库 `skills/arch-tutor`、`skills/arch-examiner`、`skills/arch-auditor` 三个目录复制到对应客户端的 `skills/` 目录 |
| **Cursor** | 将 `skills/arch-auditor/SKILL.md` 等规则写入项目 `.cursor/rules/`，或在对话中直接引用本地文件 |

详细图文步骤请参阅：[主流 AI 平台安装与接入指南](/ai-kit/install-guides)。

| **[Week 5](/guide/week-05-tdd-migration)** | TDD 5 类考题、架构棘轮、绞杀者渐进迁移 vs 推倒重写 | 1. 精读 Week 5 与棘轮样板；2. 搜 TDD 与绞杀者模式科普；3. 完成 3 题自检；4. 找考官过 Week 5 关 | 当 AI 劝你“删掉旧代码全部重来更快”时，能拿出 3 条重写红线要求它走原地渐进改造 |

## 四、日常指挥编程 AI 的标准实操 SOP

不管你用的是哪家编程 AI，只要卡住这 **4 个节点**，AI 几乎不可能把你的项目改崩：

1. **阶段 1：派活前（30 秒立规矩）**  
   发需求时顺带补一句：*“先别急着改代码。请先用 3 句话用大白话告诉我：这次改动属于业务大脑、外部接口还是本机环境？会动哪几个文件？改完后你打算用哪 3 条边界/异常测试证明没弄坏老功能？”*
2. **阶段 2：AI 交方案时（拍板前核对 Q01–Q04）**  
   打开 [10 条反问清单](/toolkit/review-checklist) 勾选阶段 A：严防盲目推倒重写、严防反向耦合、严防泄露隐私或 AI 自批、剔除顺带修改的无关文件。
3. **阶段 3：AI 动笔前（立考卷核对 Q05–Q06）**  
   确认它已写出至少覆盖“正常/边界/异常/越权”的自动测试点，并声明不擅自删已有文件、测试临时文件放系统临时目录。
4. **阶段 4：AI 宣布“改完了”时（交差验货核对 Q07–Q10）**  
   **绝不轻信“理论上全过了”**——要求它贴出**最后一笔修改完成后**真实运行的测试命令与通过条数，确认老测试一条没被删或跳过，最后让它用 3 点大白话交代“改了什么文件、变了什么行为、还有什么遗留”。

## 五、本地离线阅读、开发预览与日常维护手册

### 5.1 用 Obsidian 离线阅读与记笔记
1. 将本项目克隆或存放在本机任意目录（例如 `<LOCAL_REPO>/arch-pilot`）；
2. 打开 **Obsidian** → 点击打开本地文件夹作为库 → 选择 `arch-pilot/docs`；
3. 即可离线阅读全部教程、样板与工具表。
- **提醒**：个人学习心得建议记在你自己的私有笔记库里，**不要把个人隐私路径、密钥或私有记录直接写进 `docs/` 并推送到公开仓库**。

### 5.2 在本机浏览器预览完整交互网站
前置依赖：Node.js 20+、Python 3.10+。在仓库根目录打开终端执行：

```bash
cd <LOCAL_REPO>/arch-pilot
npm install
npm run docs:dev
```

启动后在浏览器访问 **`http://localhost:5173/arch-pilot/`**（注意路径末尾带有 `/arch-pilot/`）即可本地体验中文搜索、Mermaid 图表与交互式清单。按 `Ctrl + C` 停止预览。

### 5.3 补充新内容与推送上线的标准流程

1. **按位置修改文件**：
   - 加新术语：编辑 `docs/toolkit/glossary.md`（标题末尾须带 `{#锚点}`，且包含 `一句话生活类比`）；
   - 加离线踩坑题：编辑 `docs/ai-kit/exam-bank.md`；
   - 改陪学提示词：同时更新 `prompts/` 与 `skills/` 里的内容和版本号，并同步更新 `docs/ai-kit/*.md` 页面上显示的版本号（网页正文会自动引用 `prompts/*.prompt.md` 源文件，不用重复粘贴）。
2. **推送前一键跑完 5 道自动门禁**：
   ```bash
   npm run check:all
   ```
   依次检查脱敏与示例大小（`GATE-01/02`）、套件同步（`GATE-03`）、可读性与 Mermaid 规范（`GATE-05`）、14 条门禁单元测试，以及 VitePress 死链与全量静态构建（`GATE-04`）。
3. **推送自动更新线上站**：
   ```bash
   git add .
   git commit -m "docs: 更新内容简述"
   git push
   ```
   推送到 `main` 后，GitHub Actions 会自动重新跑通 5 道门禁并在约 30 秒内将最新版本部署至在线文档站。

## 六、常见问题与排障指南

| 遇到的问题 | 原因说明 | 一秒解决方法 |
| :--- | :--- | :--- |
| 本地 `npm run docs:dev` 打开 `http://localhost:5173/` 显示 404 | 为了适配 GitHub Pages 子路径，站点配置了 `base: '/arch-pilot/'` | 浏览器访问带前缀的 **`http://localhost:5173/arch-pilot/`** 即可 |
| 跑 `npm run check:all` 在 `check:sanitize` 报错 | 新写的内容里不小心带入了真实用户路径前缀、密钥格式、受限敏感词，或 `examples/` 示例超过 60 行 | 看报错的文件名和行号，改用 `<HOME>/projects/...` 等脱敏占位写法或精简示例代码 |
| 改完提示词跑 `check:sync` 报错 | `prompts/*.prompt.md`、`skills/*/SKILL.md` 和 `docs/ai-kit/*.md` 三处版本号不一致 | 把三处版本号改为完全一致（如全部改为 `1.0.1`） |
| 网页里勾选的《10 条反问清单》换电脑或清缓存后重置了 | 站点是零服务器纯静态托管，勾选状态保存在你当前浏览器的本地存储里 | 正常现象，无隐私上传风险；重用只需重新勾选即可 |
| 点击「一键复制提示词」未自动写入剪贴板 | 部分内嵌浏览器或非 HTTPS 本地环境限制了剪贴板权限 | 点旁边的 **「展开查看」**，手动全选正文复制即可 |
| 刚 `git push` 完刷新线上网页还没变化 | GitHub Actions 正在执行验证与 Pages 部署（通常需 30–40 秒） | 打开仓库 Actions 页面看到绿勾后强刷浏览器（`⌘⇧R`）即可 |
