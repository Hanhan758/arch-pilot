## 新手最容易中招的 3 种 AI “话术陷阱”

1. **“为了代码更优雅，我顺手把整个旧模块重构了一下”**  
   → 立刻用 **Q01 + Q04 + Q08** 拦住：问清楚有没有删老防线、动了多少无关文件、原本那套老测试还全绿吗？
2. **“所有边界情况我都考虑过了，测试全部通过”**  
   → 立刻用 **Q07** 追问：“是你在改完最后一版代码后亲手跑通的，还是改之前跑的？贴出测试命令和具体通过数量（跳过算几条）。”
3. **“因为需要读取那个数据，我让核心层直接导入了工具脚本，很方便”**  
   → 立刻用 **Q02 + Q10** 拦截：这叫反向耦合，今天图方便连成死结，下个月再想拆出来复用或打包时就会牵一发而动全身。
